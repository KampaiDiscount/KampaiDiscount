# Hey, I'm Kampai 👋

1988-born dude, anime fan, and hands-on tinkerer building practical Linux, wireless, and security tools.

I like turning fragile setup notes into repeatable installers, diagnostics, and small utilities that are easier to trust and maintain.

## Featured projects

### [Install the ALFA AWUS1900 Driver on Kali Linux](https://github.com/KampaiDiscount/kali-awus1900-deploy)

A one-command ALFA AWUS1900 / RTL8814AU driver installer and recovery tool for Kali Linux, with safe DKMS rollback, native-driver fallback, diagnostics, and reversible monitor-mode helpers.

### [AWUS1900 Surveyor](https://github.com/KampaiDiscount/awus1900-surveyor)

A stable, autonomous passive 2.4/5 GHz wireless surveyor for the ALFA AWUS1900 on Kali Linux.

### [WiFi Pineapple Mark VII Connection Manager](https://github.com/KampaiDiscount/Pineapple-MarkVII-Connection-Manager)

Windows and Debian/Linux connection managers for USB monitoring, Internet sharing, repair, diagnostics, and GUI access.
